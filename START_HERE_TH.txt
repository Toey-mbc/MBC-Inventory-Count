กรณีอัปเดตจากชุดก่อนหน้าและพบข้อความ
"column profiles.access_mode does not exist"

1. เข้า Supabase > SQL Editor
2. เปิดไฟล์ RUN_THIS_SQL_FIX_ACCESS_MODE_ERROR.sql
3. คัดลอกทั้งหมดแล้วกด Run
4. นำไฟล์โปรเจกต์ชุดนี้ขึ้น GitHub
5. Vercel จะ Deploy ใหม่ หรือกด Redeploy โดยปิด Build Cache

สิทธิ์ผู้ใช้งานในชุดนี้ไม่ใช้คอลัมน์ access_mode อีกแล้ว
- viewer = อ่าน
- counter / warehouse_manager / sale_support = แก้ไข
- admin = ผู้ดูแลระบบ

หน้า Login ใช้ Username ตามเดิม ไม่ต้องกรอก @mbc.internal
ระบบไม่บังคับเปลี่ยนรหัสผ่านครั้งแรก
